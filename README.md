# shades of revenge ♡

versão simplificada para subir no github pelo celular, sem pastas.

## arquivos
- `shades-of-revenge.json` → tema
- `shades-icons.js` → plugin com ícones fofinhos embutidos
- `repo.json` → descrição simples do pack
- `README.md` → instruções

## subir no github
1. abra seu repositório
2. clique em **add file**
3. clique em **upload files**
4. envie estes 4 arquivos
5. commit

## instalar o tema
abra o arquivo `shades-of-revenge.json`, toque em **raw** e copie o link.
depois no revenge:
**settings → themes → +** e cole o raw.

## instalar o plugin
abra o arquivo `shades-icons.js`, toque em **raw** e copie o link.
depois no revenge:
**settings → plugins → +** e cole o raw.

## observação
o plugin é experimental. ele troca os ícones que conseguir reconhecer e deixa o resto normal.
